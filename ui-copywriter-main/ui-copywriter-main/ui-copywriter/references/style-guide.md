# Style Guide

## 1. Capitalization (English)

Use **Sentence case** only: capitalize first word, lowercase rest (except proper nouns).

Applies to: titles, buttons, menus, dialog text.

| ✅ Correct | ❌ Incorrect |
|-----------|-------------|
| New chat | New Chat |
| Chat history | Chat History |
| About us | About Us |

## 2. Spacing (CJK — 盘古之白)

Add one half-width space between Chinese characters and English words or numbers.

| ✅ Correct | ❌ Incorrect |
|-----------|-------------|
| 欢迎使用 OK Computer | 欢迎使用OK Computer |
| 剩余额度 2 GB | 剩余额度2GB |

Exception: No space needed if separated by line breaks.

See `punctuation.md` for detailed punctuation and spacing interaction rules.
See `numbers-and-units.md` for number, time, and currency formatting.
