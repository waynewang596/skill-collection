## Actions

| CN | EN | Notes |
|----|-----|-------|
| 登录 | Log in | Verb phrase: two words. Noun/adjective: "Login". Never use "登陆". |

| 注册 | Sign up | More conversational than "Register". |
| 新建会话 | New chat | |

| 复制 | Copy | |
| 分享 | Share | |
| 我知道了 | Got it | For toasts or onboarding confirmations. Never use "知道了". |
| 添加 | Add | Never use "增加". |
| 新建 | New / Create | Never use "增加". |
| 上传 | Upload | Never use "增加". |
| 搜索 | Search | Never use "查找". |
| 查看 | View | Never use "查阅". |
| 发布 | Publish / Post | Never use "发表". |
| 清空 | Clear | |
