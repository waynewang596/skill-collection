## 第三章：熔断级别定义

### A级熔断（一票否决）
- 触发条件：最严重违规
- 处理方式：该题/整批立即作废，必须重来
- 适用铁律：一、二、三、六、九、十二、十八、十九、二十、二十二、二十六、二十八、二十九、三十

### B级熔断（永久熔断）
- 触发条件：严重质量问题
- 处理方式：该题作废，相关考点/题型冻结
- 适用铁律：四、五、七、八、十、十三、十七、二十三、二十四、二十五、二十七

### C级熔断（预警熔断）
- 触发条件：进度偏离或需要强制调整
- 处理方式：预警+强制修正后续题目
- 适用铁律：十一、十四、十五、十六、二十一

## 第四章：校验检查清单

### 4.1 每5题中间校验
- [ ] 1. 答案一致性检查（actual vs 预设）-> 铁律二十八/A级
- [ ] 2. 数字题数量检查（是否在18-20范围）-> 铁律八/B级
- [ ] 3. 否定性设问数量检查（>=30%进度）-> 铁律十六/C+A级
- [ ] 4. 考点覆盖率检查（>=90%*当前进度）-> 铁律十二/A级
- [ ] 5. 同考点上限检查（<=3）-> 铁律十三/B级
- [ ] 6. 连续肯定式检查（<=3）-> 铁律十六/C级

### 4.2 最终50题完整校验
- [ ] 1. 30条铁律逐条检查
- [ ] 2. 答案组合频次检查（不超标）
- [ ] 3. 两章题量平衡检查
- [ ] 4. 文档三区分布检查
- [ ] 5. 否定性设问最终>=15 -> 铁律九/A级
- [ ] 6. 解析绝对未混入 -> 铁律二十九/A级

### 4.3 否定性设问硬约束校验（V13.0新增）

## 第五章：分阶段交付校验（V13.0新增）

### 第一阶段交付校验（题目文件）
- [ ] 只含题干+选项+答案速查表
- [ ] 不含任何解析内容
- [ ] 不含选项正确性标注（如"A. xxx（正确）"）
- [ ] 答案只在速查表中，不在题目正文中

### 第三阶段启动条件
- [ ] 用户明确下达包含"生成解析"关键词的命令
- [ ] 已完成第一阶段+第二阶段交付
- [ ] 解析按排序后题目顺序逐题生成
- [ ] 解析内容以PDF实际内容为准
