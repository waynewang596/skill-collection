# 命题十步法（V13.0最终版）—— 分阶段生成 + 全铁律熔断

## 第一阶段：题目生成（Step 0-9）

### Step 0：预设答案序列（反向生成基础）
1. 先生成50题的预设答案序列（A/B/C/D/AB/AC/.../ABCDE等）
2. 校验规则：
   - 连续相同答案不超过2题
   - 各答案组合频次不超过配额上限
   - ABCDE全选<=1
   - 50题中否定性设问对应位置标记（至少15个位置）
3. 序列冻结后不得修改

### Step 1：考点盘点+追踪系统初始化
1. 读取两章PDF，盘点全部考点
2. 初始化追踪字典：
```python
tracking = {
    "questions": [],      # 已生成题目列表
    "used_points": {},    # 考点使用次数 {考点名: 次数}
    "actual_answers": [], # 实际答案序列（必须与预设一致）
    "digital_count": 0,   # 数字题计数
    "negative_count": 0,  # 否定性设问计数
    "ch6_done": 0,        # 第6章已出题数
    "ch7_done": 0,        # 第7章已出题数
    "consecutive_pos": 0, # 连续肯定式计数（V13.0 C级熔断）
    "consecutive_neg": 0, # 连续否定式计数
}
```
3. 计算否定性设问目标位置（至少15个位置分散在50题中）

### Step 2：逐题生成循环（Q1-Q50）

对每道题执行Step 3-8：

### Step 3：确定当前题目标签
1. 查看预设答案序列中第N题的答案组合
2. 根据否定性设问目标位置判断本题为肯定式或否定式
3. **V13.0 C级熔断检查**：
   ```
   if consecutive_pos >= 3:
       本题必须是否定式设问
       触发原因："C级熔断：连续3题肯定式，强制否定"
   ```

### Step 4：选择考点
1. 优先选择使用次数<3的考点
2. 优先选择新考点（近1年新增/修订）
3. 平衡两章题量（第6章约15题，第7章约35题）
4. 避免与前题在考点/法规/情境上重复

### Step 5：读取PDF原文锚定
1. 使用read_file读取对应PDF页面原文
2. 确定命题依据的具体段落
3. 提取关键数字/比例/期限（数字题）或核心概念（概念题）

### Step 6：设计干扰项（九大偷换维度）
从以下维度选择2-3个设计干扰项：
①时间/期限 ②比例/数字 ③主体 ④程序/流程 ⑤例外条款 ⑥适用条件 ⑦法律责任 ⑧概念定义 ⑨交叉引用

### Step 7：组装题目
1. 按铁律一/二/六/七组装题干+4-5选项
2. 确保正确答案与预设答案序列完全一致
3. 检查选项互斥（铁律四）
4. 检查选项长度平衡（铁律十七）

### Step 8：单题铁律校验
逐条检查30条铁律，记录通过的和不通过的：
- A级不通过→作废重来
- B级不通过→作废重来+可能冻结考点
- C级不通过→预警+强制修正

### Step 9：每5题中间校验（V13.0新增否定性设问检查）
每完成5题，执行以下校验：

1. **答案一致性**：actual_answers vs 预设序列前N题
2. **数字题进度**：digital_count是否在合理范围
3. **否定性设问进度**（V13.0新增）：
   - 第5题后：negative_count >= 1
   - 第10题后：negative_count >= 3
   - 第15题后：negative_count >= 4
   - 第20题后：negative_count >= 6
   - 第25题后：negative_count >= 7
   - 第30题后：negative_count >= 9
   - 第35题后：negative_count >= 10
   - 第40题后：negative_count >= 12
   - 第45题后：negative_count >= 13
   - 第50题后：negative_count >= 15
4. **考点覆盖**：已用考点数/总考点数 >= 当前进度*0.9
5. **连续肯定式检查**：consecutive_pos 不得超过3

**V13.0新增：否定性设问检查规则**
- 进度不足时：后续每题优先出否定式
- 连续3题肯定式后第4题强制否定式
- 第45题时若negative_count<13，剩余5题全部强制否定式

## 第二阶段：后处理（Step 10-11）

### Step 10：排序
1. 按章节编号升序（第6章在前，第7章在后）
2. 同章内按考点编号升序
3. 同考点下按题号升序
4. 重排后更新题号（Q1-Q50连续）

### Step 11：分离交付
输出文件分为两个区块：

**区块一：答案速查表**
| 题号 | 答案 | 设问类型 | 考点 |
|------|------|----------|------|
| Q1 | AB | 否定式 | 6.3 |
| ... | ... | ... | ... |

**区块二：题目正文（不含解析，不含答案标注）**
Q1. 【第6章-考点X】题干...
A. ...
B. ...
C. ...
D. ...

（注意：题目正文中选项后不加"（正确）"标记，答案只在速查表中）

## 第三阶段：解析生成（Step 12-13）——需用户命令

### Step 12：逐题生成解析
待用户下达"生成解析"命令后：
1. 按排序后的题目顺序逐题处理
2. 每题读取对应PDF原文
3. 根据PDF实际内容编制解析（不要求与预设答案完全匹配，以PDF为准）
4. 解析包含：正确答案说明+各选项正误分析+法规依据

### Step 13：解析交付
解析独立输出，与题目分离。格式：

**Q1 解析**
【答案】AB
【解析】根据《XXX》第X条规定...A选项...B选项...C选项错误因为...
【法规依据】《XXX》第X条
